# The Joke About the Demo

A one-line joke about working beside AI coding agents. Entry for the
make.fun bounty `the-joke-about-the-demo-20261121-0551`.

Run it with Node 22:

```sh
node main.ts
```

It writes the joke to `/output/entry.txt` (and a copy to `output/entry.txt`).

> My AI pair programmer built the whole demo in 40 seconds, then confidently
> demoed features that don't exist yet — the client loved them, so now
> they're on the roadmap.
